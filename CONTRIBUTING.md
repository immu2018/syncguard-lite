# Contributing

Thanks for considering a contribution to SyncGuard Lite.

1. Open an issue describing the bug or proposed improvement.
2. Keep changes focused and compatible with the supported PHP baseline.
3. Use WordPress and WooCommerce APIs; do not write product data directly to core database tables.
4. Validate permissions, nonces, input and output.
5. Test on a staging WooCommerce store.
6. Open a pull request describing the change and how it was tested.

Never include customer data, production exports, API credentials, or secrets in issues or pull requests.
